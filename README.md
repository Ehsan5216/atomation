# سامانه انبارداری متمرکز و چندکاربره واحد اعلام حریق ذوب‌آهن اصفهان
## Esfahan Steel Company (ESCO) - Centralized Multi-User Fire Alarm Warehouse Management System

> **طراح و تحلیل‌گر ارشد سیستم:** دکتر احسان ابوالقاسمی  
> **مجموعه سازمانی:** واحد اعلام حریق شرکت سهامی ذوب‌آهن اصفهان  
> **معماری:** Full-Stack متمرکز روی بستر ابری Railway به همراه پایگاه‌داده رابطه ای PostgreSQL  

---

### 📖 معرفی پروژه (Project Overview)
این سامانه یک نرم‌افزار انبارداری جامع، صنعتی، تحت وب و **برنامه پیش‌رونده وب (PWA)** است که به صورت کاملاً **Full-Stack** طراحی و پیاده‌سازی شده است. نرم‌افزار به صورت یکپارچه بر روی پلتفرم **Railway** مستقر می‌شود و تمامی سیستم‌ها (رایانه‌های انبار، لپ‌تاپ‌های اداری، تبلت‌ها و گوشی‌های تلفن همراه هوشمند) با اتصال به یک آدرس اینترنتی واحد، به صورت همزمان به یک پایگاه داده متمرکز PostgreSQL متصل هستند.

هرگونه تغییر، ثبت ورود یا خروج کالا، ویرایش موجودی قفسه‌ها، جابجایی تجهیزات و ثبت رویدادها به صورت بلادرنگ و با تراکنش‌های اتمیک (ACID) در سراسر سیستم‌های متصل همگام‌سازی می‌گردد.

---

### 🏛️ معماری یکپارچه سامانه (Architecture)
سامانه از سه لایه هماهنگ در یک سرویس واحد تشکیل شده است:
1. **Frontend (React 19 + TypeScript + Tailwind CSS):** رابط کاربری فارسی راست‌به‌چپ (RTL)، ریسپانسیو، سریع و با قابلیت نصب به عنوان PWA مستقل در موبایل و دسکتاپ.
2. **Backend (Node.js + Express REST API):** مدیریت متمرکز احراز هویت با JWT، هش ایمن رمزها (Bcrypt)، تراکنش‌های امن قفل سطری، کنترل دسترسی کاربران و ثبت دفتر ممیزی امنیتی (Audit Log).
3. **Database (PostgreSQL):** ذخیره‌سازی پایدار، متمرکز و چندکاربره اطلاعات انبارها، قفسه‌ها، کالاها، تراکنش‌ها، کاتالوگ‌های فنی و سطوح دسترسی.

```
+-------------------------------------------------------------------+
|               کاربران و دستگاه‌های مختلف (موبایل / رایانه)        |
+-------------------------------------------------------------------+
                                  │ HTTPS (نشانی واحد)
                                  ▼
+-------------------------------------------------------------------+
|                 سرویس یکپارچه Railway                             |
|                                                                   |
|   [ Frontend SPA (dist/) ] ──► [ Express Server & REST API ]      |
|                                             │                     |
+─────────────────────────────────────────────┼─────────────────────+
                                              ▼
                        +───────────────────────────+
                        |   پایگاه‌داده PostgreSQL   |
                        +───────────────────────────+
```

### ✨ ویژگی‌های کلیدی (Key Features)
* **یکپارچگی کامل Full-Stack:** اجرای فرانت‌اند، API و اتصال دیتابیس از طریق یک دامنه واحد، بدون نیاز به هاست مجزا یا GitHub Pages.
* **همگام‌سازی لحظه‌ای و چنددستگاهی:** تعریف کالا یا تراکنش در یک سیستم بلافاصله در تمام دستگاه‌های دیگر قابل مشاهده است.
* **آرم و هویت بصری رسمی:** استفاده از آرم رسمی شرکت سهامی ذوب‌آهن اصفهان در صفحه ورود و نوار مدیریت.
* **ورود ایمن و اسلاید خوش‌آمدگویی:** امنیت ورود با توکن JWT، کنترل خطای ۳ ثانیه‌ای و اسلاید خوش‌آمدگویی هوشمند به نام کاربر.
* **خروج دومرحله‌ای ایمن:** جلوگیری از خروج تصادفی کاربران حین ثبت اسناد انبار.
* **مدیریت انبارها و قفسه‌بندی چندسطحی:** ایجاد، ویرایش و پایش انبارها و قفسه‌ها به تفکیک ظرفیت و کد شناسایی.
* **کاتالوگ تخصصی قطعات اعلام حریق:** انواع دتکتورهای دودی، حرارتی، شعله، شستی‌ها، ماژول‌ها، کنترل‌پنل‌ها و آژیرها با پیوست کاتالوگ PDF.
* **ورود و خروج اکسل (Excel):** بارگذاری انبوه تجهیزات و دریافت گزارش‌های استاندارد اکسل به تفکیک انبار، موجودی و لاگ ممیزی.
* **مهاجرت آسان داده‌ها:** ابزار خودکار انتقال داده‌های محلی (مرورگر) به پایگاه‌داده مرکزی سرور با دانلود پیشتیبان پیشگیرانه.
* **قابلیت PWA با کش هوشمند:** امکان نصب بر روی صفحه اصلی گوشی و تبلت با استعلام مستقیم اطلاعات از سرور (`NetworkOnly`).

### 🚀 نحوه اجرای محلی (Local Development)

۱. **کلون کردن مخزن:**
```bash
git clone https://github.com/eabolghasemi26/firealarmstore.git
cd firealarmstore
```

۲. **نصب وابستگی‌ها:**
```bash
npm install
```

۳. **تنظیم فایل متغیرهای محیطی:**
فایل `.env.example` را به عنوان `.env` کپی کرده و در صورت تمایل رشته اتصال `DATABASE_URL` را تنظیم کنید.

۴. **اجرای سرور توسعه یکپارچه:**
```bash
npm run dev
```
سامانه بر روی آدرس `http://localhost:3000` همراه با فرانت‌اند و API فعال خواهد بود.

### 🏢 راهنمای جامع استقرار در شبکه داخلی ویندوز (Windows LAN / Workgroup Deployment)

این سامانه برای استقرار روی سرور یا رایانه ویندوزی در شبکه داخلی (LAN / Workgroup) واحد اعلام حریق کاملاً مهندسی شده است. تمامی رایانه‌ها، تبلت‌ها و گوشی‌های موجود در شبکه می‌توانند به این سرور مرکزی متصل شده و به صورت همزمان از پایگاه داده PostgreSQL استفاده کنند.

#### ۱. پیش‌نیازها
1. **نصب Node.js:** نسخه 20 یا بالاتر (LTS) از [nodejs.org](https://nodejs.org).
2. **نصب PostgreSQL:** نسخه 14 یا بالاتر روی سیستم سرور یا کانتینر شبکه. در صورت نصب لوکال در ویندوز، سرویس PostgreSQL و ابزار pgAdmin در دسترس خواهد بود. یک دیتابیس به نام `anbardari` بسازید:
   ```sql
   CREATE DATABASE anbardari;
   ```

#### ۲. تنظیم متغیرهای محیطی (`.env`)
فایل `.env` را در ریشه پروژه ایجاد کرده و مقادیر زیر را در آن قرار دهید:
```env
# اتصال به پایگاه‌داده PostgreSQL (رمز و پورت سرور را تنظیم فرمایید)
DATABASE_URL=postgresql://postgres:YourSecurePassword@localhost:5432/anbardari
DATABASE_SSL=false

# کلید رمزنگاری امن برای تولید توکن‌های JWT (حتماً یک رشته طولانی و تصادفی وارد کنید)
JWT_SECRET=zobahan-wms-prod-secret-key-super-secure-change-in-prod-2026
JWT_EXPIRES_IN=7d

# حساب کاربری مدیر ارشد سیستم (اولین بار به طور خودکار در دیتابیس ساخته می‌شود)
ADMIN_USERNAME=admin
ADMIN_INITIAL_PASSWORD=Ehsan1984*#
ADMIN_FULLNAME=دکتر احسان ابوالقاسمی

# پیکربندی سرور
PORT=3000
NODE_ENV=production
TRUST_PROXY=false
DATA_DIR_PATH=./data
UPLOADS_DIR_PATH=./uploads
```

#### ۳. نصب وابستگی‌ها و بیلد نهایی پروژه
در محیط PowerShell یا Command Prompt ویندوز:
```powershell
# ۱. نصب پکیج‌ها
npm install

# ۲. ساخت باندل بهینه‌شده فرانت‌اند و بک‌اند
npm run build

# ۳. راه‌اندازی سرور روی تمام کارت‌های شبکه (0.0.0.0:3000)
npm start
```
> **نکته:** سرور به صورت خودکار روی `0.0.0.0:3000` شنود کرده و تمام آدرس‌های IP شبکه دستگاه را در کنسول نمایش می‌دهد.

#### ۴. پیدا کردن آدرس IP سرور در شبکه محلی ویندوز
در سیستم سرور، دستور زیر را در CMD یا PowerShell اجرا فرمایید:
```cmd
ipconfig
```
آدرس `IPv4 Address` کارت شبکه فعال (مثلاً `192.168.1.100` یا `10.x.x.x`) را یادداشت نمایید.  
همچنین در خود برنامه، مدیر سیستم می‌تواند از منوی **پشتیبان‌گیری و تاریخچه سیستم ◄ مشخصات شبکه محلی سرور (LAN)** تمام آدرس‌های فعال را به همراه دکمه کپی مشاهده کند.

#### ۵. باز کردن پورت 3000 در فایروال ویندوز (Windows Firewall)
برای اینکه سایر دستگاه‌های شبکه بتوانند به سرور وصل شوند، یک بار دستور زیر را با دسترسی Administrator در PowerShell اجرا نمایید:
```powershell
New-NetFirewallRule -DisplayName "ZobAhan Warehouse System (Port 3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```
یا از طریق `wf.msc` در بخش Inbound Rules، پورت `3000` (TCP) را Allow کنید.

#### ۶. اتصال کلاینت‌ها، تبلت‌ها و گوشی‌های همراه
در مرورگر هر دستگاهی که به همان شبکه Wi-Fi یا کابل LAN متصل است، آدرس زیر را باز کنید:
```
http://192.168.1.100:3000
```
*(به جای 192.168.1.100، آدرس IP واقعی سرور خود را وارد نمایید)*

#### ۷. نصب و راه‌اندازی به عنوان PWA در گوشی و تبلت
- **در مرورگر کروم دسکتاپ:** روی آیکون نصب (Install App) در انتهای نوار آدرس کلیک کنید.
- **در اندروید (Chrome):** روی منوی سه‌نقطه ضربه زده و گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» (Add to Home screen) را انتخاب کنید.
- **در آیفون و آیپد (Safari):** دکمه Share را زده و گزینه «Add to Home Screen» را انتخاب کنید.  
برنامه با سرعت بالا، بدون نوار آدرس مزاحم و با اتصال مستقیم به دیتابیس مرکزی اجرا خواهد شد.

### 🌐 راهنمای استقرار روی Railway (Production Deployment)

استقرار سامانه روی Railway به سادگی در چند دقیقه انجام می‌شود:
1. در [Railway.app](https://railway.app) یک پروژه جدید ایجاد کرده و دیتابیس **PostgreSQL** را اضافه نمایید.
2. مخزن گیت‌هاب `eabolghasemi26/firealarmstore` را به عنوان سرویس متصل کنید.
3. متغیرهای محیطی زیر را در تب Variables سرویس تنظیم فرمایید:
   - `DATABASE_URL=${{Postgres.DATABASE_URL}}`
   - `JWT_SECRET=عبارت-تصادفی-بسیار-امن`
   - `ADMIN_USERNAME=admin`
   - `ADMIN_INITIAL_PASSWORD=رمز_عبور_مدیر`
   - `ADMIN_FULLNAME=دکتر احسان ابوالقاسمی`
   - `NODE_ENV=production`
4. دستور بیلد `npm run build` و دستور اجرا `npm start` را تایید فرمایید.
5. در بخش Networking دکمه **Generate Domain** را بزنید تا دامنه اختصاصی مانند `https://firealarmstore-production.up.railway.app` دریافت کنید.

> برای مطالعه راهنمای کامل و گام‌به‌گام با تمام جزئیات، فایل [DEPLOYMENT.md](DEPLOYMENT.md) را مطالعه فرمایید.
